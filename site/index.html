Vous pouvez aussi l’installer sans passer par le store, en mode développeur :

En attendant sa page sur le Chrome Web Store, Ronflux s’installe en mode développeur, en quatre étapes.

Télécharger le ZIP

  1. Décompressez le fichier

    Placez le dossier obtenu à un endroit où vous le garderez : le navigateur le relit à chaque démarrage.

    Une fois fait : un dossier ronflux-chrome, qui contient le fichier manifest.json.

  2. Ouvrez la page des extensions

    Copiez cette adresse dans la barre d’adresse :

    chromebraveedgeopera://extensions

    Brave : brave://extensions, Edge : edge://extensions, Opera : opera://extensions.

    Une fois fait : la page Extensions est ouverte.

  3. Activez le mode développeur

    Cliquez sur l’interrupteur « Mode développeur ».

    Une fois fait : de nouveaux boutons apparaissent en haut de la page.

  4. Chargez Ronflux

    Cliquez sur « Charger l’extension non empaquetée » et choisissez le dossier ronflux-chrome, celui qui contient le fichier manifest.json.

    Une fois fait : Ronflux apparaît dans la liste. Rechargez vos onglets Twitch.

Dans ce mode, pas de mise à jour automatique : pour une nouvelle version, remplacez le contenu du dossier par celui du nouveau ZIP, puis cliquez sur la flèche de rechargement de Ronflux dans la page des extensions.

Userscript

Vous utilisez déjà Tampermonkey ou Violentmonkey ? Ronflux existe aussi en userscript : installer le userscript. Dans Tampermonkey, réglez le mode d’injection sur « Instantané » (dans les paramètres, en mode de configuration « Avancé »).

Installez une seule version de Ronflux : si l’extension et le userscript sont présents, le second se désactive.

Questions

Ronflux collecte-t-il des données ?

Non. Ronflux n’a ni compte, ni serveur, ni statistiques : tout se passe dans votre navigateur, et l’extension n’agit que sur twitch.tv. Ce site non plus ne collecte rien : pas de cookie, pas de mesure d’audience. Le code de Ronflux est public : vous pouvez le vérifier sur GitHub.

Comment se font les mises à jour ?

Avec Firefox, toutes seules. Avec Firefox, installez la nouvelle version depuis cette page : elle remplace l’ancienne, sans rien perdre. Avec Chrome, Brave, Edge ou Opera, toutes seules si Ronflux vient du Chrome Web Store. En mode développeur, à la main : téléchargez le nouveau ZIP, remplacez le contenu du dossier, puis rechargez Ronflux depuis la page des extensions. Avec Chrome, Brave, Edge ou Opera en mode développeur, à la main : téléchargez le nouveau ZIP, remplacez le contenu du dossier, puis rechargez Ronflux depuis la page des extensions. Le userscript, lui, se met à jour par Tampermonkey ou Violentmonkey.

Une pub est passée quand même : que faire ?

Rechargez la page du live. Twitch change souvent sa façon de diffuser les pubs : si elles reviennent sur toutes les chaînes, vérifiez que vous avez la dernière version de Ronflux. Il arrive aussi que toutes les diffusions d’un live reçoivent la même pub pendant quelques dizaines de secondes ; Ronflux masque alors l’image et coupe le son jusqu’à la fin.

Ça marche sur les rediffusions et les clips ?

Non, seulement sur les lives.

L’image change-t-elle pendant une pub ?

La qualité peut baisser un moment si la diffusion sans pub ne propose pas la même. À la fin de la pub, le lecteur se recharge brièvement.

Faut-il l’extension et le userscript ?

Non, une seule version suffit. Si les deux sont installées, la seconde se désactive d’elle-même.

Ronflux est-il lié à Twitch ?

Non, Ronflux n’est pas affilié à Twitch. Il dépend de la façon dont Twitch diffuse ses lives aujourd’hui : si Twitch change son lecteur, Ronflux peut cesser de marcher jusqu’à sa version suivante.

Et les streamers ?

Les pubs font partie de leurs revenus. Pour les soutenir sans pub, Twitch propose Turbo et les abonnements aux chaînes.
